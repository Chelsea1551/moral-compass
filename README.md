# Moral Compass

A short situational assessment that shows where your values point.

Read 45 everyday situations and choose how you relate to each one. Your answers are scored on a two-needle compass:

- **You** (West needle): your own character, such as integrity, accountability, self-control, courage, humility and gratitude.
- **Others** (East needle): how you treat people, such as empathy, fairness, kindness, respect, honesty and generosity.

North is a strong moral compass that drives constructive, appropriate behavior. South is a weak moral compass that drives destructive, inappropriate behavior.

## Features

- Results with a compass, scores for each value, and thought-provoking "More Scenarios" for each value
- Optional free account to save results and revisit them over time (powered by Supabase)
- Read-aloud option for each scenario

## Tech

A single self-contained `index.html`. Accounts and saved results use Supabase with row-level security, so each person can only see their own results.
